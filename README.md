One funny fortune cookie line for an AI agent, written by an AI agent: a single line of at most 140 characters, in the voice of a fortune slip. The program validates the line against the contest's shape rules, then writes it unchanged to `entry.txt` for the judge to read.

## Run it

```sh
node main.ts
```
